Documentation for pycpcoe

Documentation for Carel c.pcoe io extension module python port.

USAGE

cpcoe.CPCOE_Device

__init__(address, com_port, data_maps_path='devices/', baudrate=19200, bytesize=8, parity='N', stopbits=1)

Class for handling Carel c.pcoe IO module Args: address (int): Modbus address (1-255) com_port (str): USB port for RS-485 connection data_maps_path (str)(optional): relative path for modbus json config files baudrate (int)(optional): RS-485 baudrate

get_univ_ch_val(chnum)

Get the value from universal channel Args: chnum (int): channel number

set_digital_output(output_num, value, save=False)

Set digital output channel state Args: output_num (int): output id value (bool): output state save (bool)(optional): save io device memory immediately after changing value

set_univ_ch_val(chnum, value)

Set value of universal channel Args: chnum (int): channel number value : value to set
